ttg.barrier local                        // Full sync (lgkmcnt(0) + s_barrier)
warpIDX = threadIdx.x / 256
warpLow = (warpIDX == 0)

=== Key Design Points ===

1. 8 sub-clusters per loop iteration: mem0, dot0, mem1, dot1, mem2, dot2, mem3, dot3
2. Dot is sliced 4 ways along K (K=64 / MFMA_K=16 = 4 slices)
3. Global loads (register path) are interleaved: A in mem0, B in mem1
4. local_store (register -> LDS writeback) is in mem3 (last memory cluster)
5. ttg.barrier local at EVERY cluster boundary (lgkmcnt(0) + s_barrier)
6. s_setprio: compute=HIGH(1), then LOW(0) after each dot
7. Asymmetric cond_barrier pre/post loop for warp offset
